# lab02 — Множества и мультимножества в SQL

**Студент:** Родионова К.М., группа ИНБО-20-23
**Вариант:** 1 (X = SP, Y = RJ)

## Определения

- **A** — множество `product_id`, купленных клиентами из SP, по delivered-заказам.
- **B** — множество `product_id`, купленных клиентами из RJ, по delivered-заказам.

## Мощности множеств

| Множество | Мощность |
|---|---|
| A | 18709 |
| B | 7672 |
| A ∪ B | 22211 |
| A UNION ALL B | 60591 |
| A ∩ B | 4170 |
| A − B | 14539 |
| B − A | 3502 |

## Проверка соотношения включений-исключений

|A ∪ B| = |A| + |B| − |A ∩ B| = 18709 + 7672 − 4170 = 22211 ✔

## Выводы

- UNION удаляет дубликаты, UNION ALL — сохраняет. Разница: 60591 − 22211 = 38380 дубликатов.
- INTERSECT и UNION коммутативны.
- EXCEPT некоммутативна: |A − B| = 14539 ≠ |B − A| = 3502.
- EXISTS-версия даёт тот же результат, что INTERSECT.
