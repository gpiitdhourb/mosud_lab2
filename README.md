# lab02 — Множества и мультимножества в SQL

**Студент:** Родионова К.М., группа ИНБО-20-23
**Вариант:** 1 (X = SP, Y = RJ)

## Определения

- **A** — множество `product_id` товаров, купленных клиентами из штата **SP**, по заказам со статусом `delivered`.
- **B** — множество `product_id` товаров, купленных клиентами из штата **RJ**, по заказам со статусом `delivered`.

## Мощности

| Множество | Мощность |
|---|---|
| |A| (DISTINCT product_id, SP) | 18 709 |
| |B| (DISTINCT product_id, RJ) | 7 672 |
| |A ∪ B| (UNION) | 22 211 |
| |A UNION ALL B| (мультимножество) | 26 381 |
| |A ∩ B| (INTERSECT) | 4 170 |
| |A − B| (EXCEPT) | 14 539 |
| |B − A| (EXCEPT) | 3 502 |

## Проверка соотношений

Включения-исключения:
|A ∪ B| = |A| + |B| − |A ∩ B| = 18 709 + 7 672 − 4 170 = 22 211

Разбиение объединения:
|A ∪ B| = |A − B| + |A ∩ B| + |B − A| = 14 539 + 4 170 + 3 502 = 22 211

Мультимножество vs множество:
|A UNION ALL B| = |A| + |B| = 26 381, а |A UNION B| = 22 211 (разница 4 170 = |A ∩ B|).

## Выводы

1. UNION удаляет дубликаты, UNION ALL — сохраняет. Разница 26 381 − 22 211 = 4 170.
2. UNION и INTERSECT коммутативны.
3. EXCEPT некоммутативна: 14 539 ≠ 3 502.
4. EXISTS-версия пересечения даёт тот же результат, что INTERSECT.
5. Без DISTINCT и с JOIN результат — мультимножество (46 448 строк у A при 18 709 уникальных product_id).
